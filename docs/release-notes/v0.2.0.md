## 新增
- 内容区在几万字符时仍然流畅，上限 8 万字符；导入文本上限 320 KB。
- 文件页的提示常驻底栏，耗时过长 / 分片过多 / 准备失败不会随内容滚动被遮住；续传输入框有 2 万字符上限并显示计数。
- 接收端进度块区分「续传中」与「等待补片」并实时显示缺片与速率；关于页可查看带格式的发布说明与第三方许可。
## 修复
- 目标窗口不再读到 Typer 自己；不足 1 秒的耗时显示毫秒，不再出现「0 秒」。
- 接收端：合并完成后按键不再被尾部结束帧干扰；帧被截断时报编码类错误，混入非帧内容时汇总提示。
## 移除
- 文件页的十六进制预览。
- 输入页右侧的信息栏，目标窗口与运行状态改到页头胶囊与底部状态条。
## 兼容
- 旧设置与续传令牌可直接沿用。
- 安装包仍为 `Typer-<版本>-setup.exe`，同目录附 `SHA256SUMS.txt` 供应用内更新校验。
