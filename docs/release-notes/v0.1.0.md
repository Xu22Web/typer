首个版本。

## 新增
- 文本模式：把内容逐字符打进当前窗口，只发真实按键，远程桌面 / 云桌面可用。
- 键盘打不出来的字符映射成英文标点或忽略，开始前提示并征求确认。
- 文件模式：文件按「每片一行」的纯文本帧发送，逐片 CRC 校验、整文件 SHA-256 复核，支持断点续传。
- 运行浮窗：贴边进度条与可拖动卡片，显示进度、剩余时间与暂停 / 停止。
- 设置、日志与关于页齐全，首次启动有新手引导。
## 兼容
- 仅支持 Windows 10/11，注入依赖 Win32 `SendInput`。
- 安装包为 `Typer-<版本>-setup.exe`，同目录附 `SHA256SUMS.txt` 供应用内更新校验。
